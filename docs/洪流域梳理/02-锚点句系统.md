# 02 · 锚点句系统

## 这个结是什么

协议领养的是一句愿景锚点句。你要它能迭代、来源多个语境、能浓缩成关键词。第 01 篇又多了三样：涂色、按小中大标题排、复习时间。这篇把这一句话的身世问清楚。

## 现在有什么

- 一条锚点句 = 一句话 + 三类之一（动机 / 观点 / 实践）。
- 来源靠「绑定」：某张卡里的一段文字 + 你当时的原话 + 这段话提出的几条锚点句。一条锚点句可以挂在多张卡上。
- 改句子是直接盖掉，旧的不留。
- 没有关键词这一层，没有层级，没有复习时间。
- 建锚点现在只有两条路：AI 锚定，或者在视频转录里点选一整句。你 6 月否决过「随意框选建锚点」。

## 结论（2026-11-20，按你的回答整理）

定了的：

- **一个锚点是一个页面，里面是一条条锚点句的块。** 一条锚点句像一个词条：某个关键词的一个重要知识点或释义。锚点是双向链接关系图上的节点。
- **来源跟着锚点句走，不跟某一版。** 锚点句可以另写一段描述，理清它和那些语境的新关系。
- **关键词：AI 提议，你认。**
- **树：AI 排。** 动机 / 观点 / 实践是根本的分类标准，留。以后编排方式不止一种（多个标准的树状图、路线图等），能看得舒服实用的形态都要试。
- **复习先不管。** 先把基底数据的创建时间、更新历史这些时间戳记清楚。
- **你真正要的是**：「一种能够看清楚全貌的所有创作介质的可迭代的锚点目录。」
