## 照着做的第一步

- 左侧栏「锚点」一节变成一份目录。最上面一层是领域，你自己建、自己起名，数量不限。
- 领域是一种结点。结点里可以再建下级结点，锚点挂在结点底下。
- 结点只用来归拢：点它是展开或收起，不能被 # 引用，没有自己的正文。
- 锚点归哪个领域由你手动定：在领域那一行点 ＋ 新建，或者把已有的锚点拖进去。
- 还没归领域的锚点排在最后，标着「还没归领域」。
- 一个锚点可以在别的领域或结点里放分身。分身那一格显示的就是这个锚点的名字和引用数，点它打开的是同一个锚点。去掉分身不影响锚点；锚点彻底删掉，分身跟着没。
- 动机 / 观点 / 实践仍然只是锚点句的分类，不用来分领域。
